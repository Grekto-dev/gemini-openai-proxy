Como Conectar Agentes ao Proxy

O proxy expõe a especificação oficial da OpenAI (`/v1/chat/completions` e `/v1/models`).

H

Hermes Agent (Recomendado)

Totalmente integrado para tool calling local

Exporta e registra automaticamente todos os 14 modelos no ~/.hermes/config.yaml e no cache do Hermes (igual ao OpenRouter!). Você pode usá-los diretamente: 

# Usar via provider registrado no config.yaml:
hermes --provider custom:google-ai-pro -m gemini-3.8-flash-high

# Ou com qualquer outro modelo do catálogo:
hermes --provider custom:google-ai-pro -m claude-sonnet-5-5-high

# Ou via variáveis de ambiente padrão OpenAI:
export OPENAI_BASE_URL="http://127.0.0.1:8000/v1"
export OPENAI_API_KEY="google-ai-pro-proxy"
hermes run "Analise os arquivos do projeto"
💡 Exportação Automática: O Hermes descobre os modelos via /v1/models e armazena em cache no provider_models_cache.json. Ao sincronizar, todos os modelos ficam acessíveis sem precisar digitar manualmente.

Py

Python (OpenAI SDK)

Integração nativa com 4 linhas

from openai import OpenAI

client = OpenAI(
    base_url="http://127.0.0.1:8000/v1",
    api_key="proxy"
)

res = client.chat.completions.create(
    model="gemini-3.8-flash-high",
    messages=[{"role": "user", "content": "Olá!"}]
)
print(res.choices[0].message.content)
